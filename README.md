# Music Player

A simple music player application created using HTML, CSS and JavaScript.

## Features

- Play and pause music
- Previous and next buttons
- Progress bar
- Volume control
- Responsive design
- Simple and clean UI

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

```bash
music-player/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Add your own song file as `song.mp3`
4. Run `index.html` in browser
